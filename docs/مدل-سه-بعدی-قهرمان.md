# تصمیم هنری و انیمیشن قهرمان

برای یکدست‌شدن سبک و اجرای سبک در Godot Compatibility، نسخهٔ جدید از ریگ برداری دوبعدی استفاده می‌کند. مدل آزمایشی سه‌بعدی نسخهٔ قبل در تاریخچهٔ Git باقی می‌ماند و دیگر دارایی runtime نیست.

مرجع: `scripts/hero_rig.gd` و `assets/art/hero/`.

- ۱۷ بخش مستقل با ترتیب لایه‌بندی مشخص.
- پاهای دو‌بندی با IK؛ حرکت پا با سرعت افقی هماهنگ است.
- حالت‌های ایستادن، حرکت، پرش، سقوط، نشستن، دش، فرود، آسیب و مرگ.
- شال، دم و دو گوش با تأخیر فاز حرکت می‌کنند.
- بازو و اسلحه از پاها مستقل‌اند؛ شلیک در حرکت و هوا ممکن است.
- artwork قهرمان در سه برابر ابعاد منطقی rasterize می‌شود و اندازهٔ ریگ مستقل می‌ماند؛ نمای نزدیک منو واضح است.
- انیمیشن قهرمان و برخورد فیزیکی مستقل‌اند؛ تغییر ظاهری اندازه، کپسول برخورد را تغییر نمی‌دهد. حالت crouch فقط بعد از بررسی سقف به حالت ایستاده برمی‌گردد.

برای بازسازی SVGها: `python3 tools/build_art.py`. این ابزار به کتابخانهٔ خارجی نیاز ندارد. برای تغییر رفتار حرکت، `scripts/player.gd` را ویرایش کن.
