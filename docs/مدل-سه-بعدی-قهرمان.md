# مدل سه‌بعدی قهرمان

قهرمان اصلی دیگر Sprite یا تصویر ثابت نیست.

## روش فعلی

مدل با Node3D و MeshInstance3D ساخته شده و هر عضو بدن Pivot مستقل دارد. سپس یک SubViewport سه‌بعدی، مدل را با دوربین Orthographic از نمای بغل رندر می‌کند و بازی دوبعدی همان خروجی زنده را نمایش می‌دهد.

یعنی تصویر از قبل ذخیره نشده است؛ هر فریم از مدل سه‌بعدی واقعی رندر می‌شود.

## فایل‌ها

- `scripts/hero_model_3d.gd` ساخت مدل، مفصل‌ها و انیمیشن
- `scripts/player.gd` اتصال مدل سه‌بعدی به کنترل بازیکن

## مرحله‌ی حرفه‌ای بعدی

برای مدل نهایی با فرم نرم، صورت حرفه‌ای، خز، لباس و deformation طبیعی، ابزار مناسب **Blender** است.

مسیر نهایی پیشنهادی:

1. مدل‌سازی Mesh اصلی در Blender
2. ساخت Armature
3. Bone برای ستون فقرات، سر، گوش‌ها، دست‌ها، پاها و دم
4. Weight Painting
5. IK برای پا و دست
6. ساخت Actionهای Run / Jump / Shoot / Crouch
7. Export به GLB
8. Import مستقیم GLB در Godot
9. استفاده از AnimationTree برای ترکیب انیمیشن‌ها

نسخه‌ی فعلی یک مدل سه‌بعدی واقعی و مفصلی است، اما از Primitive Meshها ساخته شده و نقش پایه‌ی فنی Rig را دارد؛ مدل هنری نهایی باید در Blender Sculpt/Model شود.
