# VELOCITY — Echoes of the Core

بازی اکشن و سکوبازی دوبعدی برای **Godot 4.5**؛ پنج مرحلهٔ متصل، پنج باس، شخصیت و گرافیک اختصاصی و موسیقی اصلی. ریتم حرکت و مبارزه از بازی‌های کلاسیک مثل Jazz Jackrabbit الهام گرفته، ولی شخصیت‌ها، محیط‌ها و موسیقی این پروژه اختصاصی هستند.

## اجرای سریع

1. **شاخهٔ `games`** را از GitHub با **Code → Download ZIP** دانلود و از حالت فشرده خارج کن.
2. در نسخهٔ معمولی **Godot 4.5**، گزینهٔ **Import** را بزن و فایل **`project.godot`** همین پوشه را انتخاب کن. نسخهٔ .NET لازم نیست.
3. صبر کن فایل‌ها Import شوند؛ سپس **F5 / Run Project** را بزن.
4. در منو **Begin Journey** را انتخاب کن.

بازی برای اجرا به اینترنت، Python، Blender، افزونه یا دانلود فایل گرافیکی/صوتی نیاز ندارد. همهٔ دارایی‌ها داخل مخزن هستند. پروژه با رندرر **Compatibility** تنظیم شده است.

## پنج دنیا

| مرحله | محیط | باس | ویژگی مسیر |
|---|---|---|---|
| ۱ — Verdant Frontier | جنگل و خرابه‌های باستانی | Mossback Warden | آموزش حرکت، فنر و مسیرهای مرتفع |
| ۲ — Brass Skyways | شهر آسمانی و اسکله‌های هوایی | Admiral Manta | سکوهای متحرک و پرتوهای زمان‌بندی‌شده |
| ۳ — Prismatic Depths | غار کریستالی | Prism Oracle | سکوهای شکننده و مسیرهای چندارتفاعی |
| ۴ — Ember Engine | مجتمع کوره و رآکتور | Furnace Titan | ترکیب تله، مبارزه و سکوبازی |
| ۵ — Eclipse Citadel | قلعهٔ تاریک | Varkon | ترکیب مهارت‌ها و باس نهایی |

هر مرحله سه چک‌پوینت و سه Core Shard مخفی دارد. بعد از شکست باس وارد دروازهٔ انتهای مرحله شو تا مرحلهٔ بعد باز شود. چک‌پوینت‌ها در همان نوبت بازی نگه داشته می‌شوند؛ مراحل بازشده، رکوردها و تنظیمات روی دستگاه ذخیره می‌شوند.

## کنترل‌ها

| کار | کیبورد / ماوس | دستهٔ استاندارد |
|---|---|---|
| حرکت | A / D یا چپ / راست | استیک چپ / D-pad |
| پرش و پرش دوم | Space / W / بالا | A |
| شلیک | J / Z / کلیک چپ | X |
| دش | Shift / K / X | B |
| تعویض سلاح | Q / E یا ۱، ۲، ۳ | RB |
| نشستن | S / پایین | پایین D-pad |
| توقف | Esc / P | Start |
| تمام‌صفحه | F11 | تنظیمات |

پرش را بیشتر نگه دار تا بالاتر بروی. هنگام دش در برابر ضربه مصون هستی و می‌توانی به دشمن‌های عادی آسیب بزنی. با فرود روی بیشتر دشمن‌ها نیز آسیب وارد می‌شود.

- **Pulse:** تیر معمولی بدون محدودیت مهمات.
- **Scatter:** سه تیر پخش‌شونده؛ مصرف ۸ واحد انرژی.
- **Nova:** تیر انفجاری؛ مصرف ۱۲ واحد انرژی و آسیب به دشمن‌های اطراف.
- انرژی خودکار برمی‌گردد. اگر انرژی کافی نداشته باشی، شلیک به Pulse برمی‌گردد.
- **Assist Mode** زمان مصونیت بعد از ضربه را بیشتر و دشمن‌ها را آسان‌تر می‌کند؛ تغییر سلامتی باس از بارگذاری یا تلاش بعدی اعمال می‌شود.
- صدای موسیقی، افکت‌ها، لرزش دوربین و کنترل لمسی مستقل تنظیم می‌شوند.

## گرافیک و انیمیشن

سبک نهایی این نسخه، گرافیک برداری دوبعدی با سایه‌روشن، پس‌زمینهٔ چندلایه و پارالاکس است. مدل سه‌بعدی موقت نسخهٔ قبل از مسیر اجرا حذف شده است.

قهرمان ۱۷ بخش مجزا دارد: پاهای مفصلی با IK، دست‌ها، سر، گوش‌ها، دم، شال و اسلحه. دویدن، پرش، سقوط، فرود، نشستن، دش، واکنش به آسیب و پس‌زدن اسلحه در زمان اجرا انیمیت می‌شوند. دشمن‌های زمینی پاهای مستقل دارند؛ پهپادها بال و حرکت شناور دارند؛ باس‌های زمینی بازوهای مستقل و حمله‌های دارای هشدار بصری دارند.

۵۸ فایل SVG اصلی، هفت قطعهٔ موسیقی حلقه‌شونده و ۱۲ افکت صوتی در پروژه قرار دارد. ابزار بازسازی دارایی‌ها در `tools/` است و فقط برای ویرایش و تولید دوبارهٔ آن‌ها کاربرد دارد.

## ساختار

- `scenes/main.tscn` — صحنهٔ آغاز پروژه
- `scripts/main.gd` — منوها، تنظیمات، توقف و انتقال مراحل
- `scripts/campaign.gd` — مسیرها و داده‌های پنج مرحله
- `scripts/level.gd` — ساخت محیط، چک‌پوینت، آرنا و روند مرحله
- `scripts/player.gd` / `hero_rig.gd` — کنترل و انیمیشن قهرمان
- `scripts/enemy.gd` / `boss.gd` — دشمن‌ها و باس‌ها
- `scripts/projectile.gd` — برخورد پیوستهٔ گلوله با ray sweep
- `scripts/game_state.gd` — ذخیرهٔ اتمیک تنظیمات و پیشرفت
- `assets/art/` / `assets/audio/` — تمام گرافیک و صدا
- `tests/smoke.tscn` — تست یکپارچهٔ بازی با فیزیک واقعی Godot

## آزمون و خروجی

```bash
GODOT_BIN=/path/to/godot bash tools/verify.sh
```

گزارش دقیق تست‌ها و محدودیت‌های بررسی در [docs/VALIDATION.md](docs/VALIDATION.md) است. برای خروجی اجرایی ویندوز یا لینوکس، [راهنمای اجرا و بیلد](docs/راهنمای-اجرا-و-بیلد.md) را ببین.

هیچ نرم‌افزاری را نمی‌توان مطلقاً بدون باگ تضمین کرد؛ تست‌های ثبت‌شده نشان می‌دهند چه مسیرهایی بررسی شده‌اند. تست تعادل سختی با بازیکن انسانی و کنترلر فیزیکی همچنان ارزشمند است.
