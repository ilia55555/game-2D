# راهنمای اجرای بازی، بیلد و دیپلوی

این راهنما برای کسی نوشته شده که قبلاً با Godot کار نکرده است.

---

## اول معنی این سه کلمه را بدان

### اجرا یا Run

یعنی بازی را داخل Godot باز می‌کنی و برای تست اجرا می‌کنی.

در این حالت هنوز فایل نصبی یا `.exe` نساخته‌ای.

### بیلد یا Export

یعنی Godot پروژه را به یک فایل قابل اجرا برای دستگاه مقصد تبدیل می‌کند.

مثلاً:

- Windows → فایل `.exe`
- Android → فایل `.apk` یا برای انتشار در فروشگاه `.aab`

### دیپلوی

یعنی بیلدی که ساخته‌ای را روی یک دستگاه نصب کنی یا برای دیگران منتشر کنی.

مثلاً نصب APK روی گوشی یا ارسال نسخه‌ی Windows برای تست.

---

# بخش ۱ — اجرای پروژه روی کامپیوتر

## چه چیزی باید نصب کنم؟

برای تست اولیه‌ی بازی روی PC فقط **Godot 4.x** لازم است.

نسخه‌ی معمولی Godot را بگیر. برای این پروژه نسخه‌ی .NET لازم نیست، چون کدها با GDScript نوشته شده‌اند.

سایت رسمی:

https://godotengine.org/download/

## مرحله ۱ — دانلود پروژه از GitHub

وارد مخزن `game-2D` شو و مطمئن شو شاخه‌ی `games` را می‌بینی.

دو راه داری:

### روش ساده

از GitHub گزینه‌ی **Code → Download ZIP** را بزن.

فایل ZIP را Extract کن.

### روش Git

اگر بعداً GitHub Desktop نصب کردی، می‌توانی Repository را Clone کنی. برای شروع لازم نیست.

---

## مرحله ۲ — باز کردن پروژه در Godot

Godot را اجرا کن.

در صفحه‌ی Project Manager:

1. روی **Import** بزن.
2. وارد پوشه‌ای شو که پروژه را از ZIP خارج کرده‌ای.
3. فایل `project.godot` را انتخاب کن.
4. روی **Import & Edit** بزن.

اگر پروژه درست باز شود، وارد محیط ادیتور Godot می‌شوی.

---

## مرحله ۳ — اجرای بازی

بالای Godot دکمه‌ی ▶ وجود دارد.

روی آن بزن.

می‌توانی از کلید **F6** یا **F5** نیز استفاده کنی.

اگر Godot از تو پرسید Main Scene کدام است، فایل زیر را انتخاب کن:

`scenes/main.tscn`

---

## کنترل‌های بازی

- حرکت: A و D
- حرکت جایگزین: جهت چپ و راست
- دویدن: Shift
- پرش: Space
- پرش جایگزین: W یا جهت بالا
- تیراندازی: J یا K

# بخش ۲ — وقتی نسخه‌ی جدید روی GitHub گذاشته شد چه کنم؟

اگر پروژه را به صورت ZIP دانلود کرده‌ای، ساده‌ترین روش این است:

1. نسخه‌ی جدید را دوباره از شاخه‌ی `games` دانلود کن.
2. ZIP را Extract کن.
3. پروژه‌ی جدید را با Godot باز کن.

اگر بعداً GitHub Desktop را نصب کنیم، فقط با یک دکمه **Pull** نسخه‌ی جدید را دریافت خواهی کرد.

# بخش ۳ — گرفتن فایل EXE برای Windows

برای اجرای مستقیم داخل Godot فقط خود Godot کافی است، اما برای ساخت فایل مستقل Windows باید **Export Templates** همان نسخه‌ی Godot را هم نصب کنی.

## نصب Export Templates

داخل Godot:

1. از منوی **Editor** وارد **Manage Export Templates** شو.
2. گزینه‌ی دانلود و نصب Templateها را انتخاب کن.
3. صبر کن تا Template مربوط به همان نسخه‌ی Godot نصب شود.

## ساخت خروجی Windows

بعد از نصب Templateها:

1. پروژه را باز کن.
2. از منوی **Project → Export** برو.
3. روی **Add...** بزن.
4. **Windows Desktop** را انتخاب کن.
5. برای شروع تنظیمات پیش‌فرض کافی است.
6. روی **Export Project** بزن.
7. یک پوشه مثل `exports/windows` انتخاب کن.
8. نام خروجی را مثلاً `ProjectVelocity.exe` قرار بده.
9. خروجی را بساز.

Godot هنگام Export فایل‌های پروژه را برای نسخه‌ی قابل اجرا آماده می‌کند. مستندات رسمی Godot هم روش Export از طریق preset ویندوز را توضیح می‌دهد.

راهنمای رسمی:

https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_windows.html

# بخش ۴ — تست روی Android

راه‌اندازی Android از Windows کمی بیشتر کار دارد. فعلاً اول نسخه‌ی PC را اجرا و تست کن. وقتی آن نسخه سالم بود، Android را تنظیم می‌کنیم.

برای گرفتن خروجی Android روی کامپیوتر به این موارد نیاز داری:

- Godot 4
- Export Templates
- Java / OpenJDK
- Android SDK
- در روش ساده، نصب Android Studio راحت‌ترین راه برای گرفتن SDK است

مستندات Godot استفاده از **OpenJDK 17** را به‌عنوان انتخاب پیشنهادی برای سازگاری ذکر می‌کند.

## مراحل کلی Android

1. Android Studio را نصب کن.
2. Android SDK را نصب کن.
3. OpenJDK را نصب کن.
4. وارد **Editor → Editor Settings** در Godot شو.
5. بخش Android را پیدا کن.
6. مسیر **Java SDK Path** را تنظیم کن.
7. مسیر **Android SDK Path** را تنظیم کن.
8. وارد **Project → Export** شو.
9. یک preset از نوع **Android** اضافه کن.
10. خروجی APK بگیر.

راهنمای رسمی:

https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html

# بخش ۵ — نصب APK روی گوشی برای تست

بعد از ساخته شدن فایل APK، برای تست شخصی می‌توانی آن را روی گوشی Android نصب کنی.

ممکن است Android از تو اجازه‌ی نصب برنامه از منبع خارج از فروشگاه را بخواهد.

برای نسخه‌ی تستی این طبیعی است.

برای انتشار عمومی در Google Play بعداً باید تنظیمات Release، امضای برنامه و فایل مناسب انتشار را جداگانه انجام دهیم.

---

# بخش ۶ — فعلاً چه چیزی از تو می‌خواهم؟

در مرحله‌ی فعلی فقط این کارها را انجام بده:

1. Godot 4 را نصب کن.
2. شاخه‌ی `games` را دانلود کن.
3. `project.godot` را Import کن.
4. بازی را Run کن.
5. حرکت و پرش و تیراندازی را امتحان کن.
6. اگر Error دیدی از صفحه عکس بگیر یا متن Error را بفرست.
7. اگر بازی اجرا شد، بگو چه چیزی در حس حرکت، سرعت یا پرش خوب یا بد است.

فعلاً لازم نیست Android Studio یا ابزارهای موبایل را نصب کنی.

اول باید مطمئن شویم نسخه‌ی PC بدون خطا اجرا می‌شود.

# اگر بازی اجرا نشد

این موارد را برای من بفرست:

- نسخه‌ی Godot
- عکس کامل Error
- متن قرمز پایین Godot
- بگو Error هنگام باز کردن پروژه رخ داده یا هنگام Run

من کد را در Repository اصلاح می‌کنم و تو فقط نسخه‌ی جدید را دوباره تست می‌کنی.
