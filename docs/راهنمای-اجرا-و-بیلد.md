# اجرای بازی در Godot

نسخهٔ آزمایش‌شده: **Godot 4.5 stable، نسخهٔ معمولی، بدون .NET**.

## دانلود و باز کردن

1. وارد شاخهٔ **games** مخزن شو.
2. **Code → Download ZIP** را انتخاب کن و ZIP را کامل استخراج کن.
3. Godot را باز کن. در Project Manager روی **Import** بزن.
4. فایل `project.godot` را از پوشهٔ استخراج‌شده انتخاب کن.
5. **Import & Edit** را بزن و منتظر تمام‌شدن Import بمان.
6. **F5** را بزن. صحنهٔ اصلی از قبل تعیین شده و منوی بازی باز می‌شود.

فایل‌ها را از داخل ZIP اجرا نکن. نیازی به ساخت پروژهٔ جدید، انتخاب زبان C#، جابه‌جایی فایل‌های assets یا نصب Python نیست.

## اگر مخزن را با Git گرفته‌ای

```bash
git clone --branch games --single-branch https://github.com/ilia55555/game-2D.git
```

برای نسخهٔ جدید، در همان پوشه `git pull` بزن. Godot فایل‌های تغییریافته را دوباره Import می‌کند. تغییرهای شخصی ذخیره‌نشده را قبل از Pull بررسی کن.

## خروجی EXE یا Linux

برای بازی داخل Godot این قسمت لازم نیست.

1. در Godot به **Editor → Manage Export Templates** برو و Export Template مربوط به **همان نسخهٔ Godot** را نصب کن.
2. **Project → Export** را باز کن.
3. دو preset آماده وجود دارد: **Windows Desktop** و **Linux**.
4. پوشهٔ خروجی را بساز و **Export Project** را بزن. برای خروجی نهایی، **Export With Debug** را بردار.
5. گزینهٔ Embed PCK فعال است؛ با این حال اگر Godot فایل همراهی ساخت، تمام محتوای پوشهٔ خروجی را با هم نگه دار.

خروجی Windows و کنترلر فیزیکی در این محیط اجرا نشده‌اند؛ اعتبارسنجی اصلی با Godot لینوکس انجام شده است.

## ذخیرهٔ بازی

مراحل بازشده، بهترین امتیاز/زمان/آیتم‌ها و تنظیمات در `user://velocity_save.json` ذخیره می‌شوند. جای واقعی آن را می‌توان از **Project → Open User Data Folder** دید. چک‌پوینت درون هر مرحله برای همان نوبت بازی است؛ ادامه از منو از ابتدای آخرین مرحلهٔ بازشده شروع می‌شود.

## اجرای تست

```bash
godot --headless --path . --import
godot --headless --path . --fixed-fps 60 --scene res://tests/smoke.tscn -- --test
```

گزینهٔ `--test` جلوی تغییر فایل ذخیرهٔ بازیکن و پخش صدا را می‌گیرد. تست ذخیره‌سازی از یک فایل موقت جداگانه استفاده می‌کند.

## اجرای مستقیم یک مرحله برای توسعه

```bash
godot --path . -- --stage 0
```

شمارهٔ مرحله از صفر تا چهار است. این میان‌بر فقط در نسخهٔ debug/editor فعال است و مسیر عادی بازی از منو می‌گذرد.
