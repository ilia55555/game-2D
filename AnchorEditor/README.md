# Rabbit Anchor Editor

این ابزار وب مستقل برای آماده‌سازی قطعه‌های Crop‌شدهٔ خرگوش است. فایل `index.html` را مستقیماً در مرورگر باز کنید؛ هیچ فایل یا تصویری به سرور ارسال نمی‌شود.

## خروجی‌های هماهنگ

برای هر قطعه سه فایل هم‌نام بگیرید:

- PNG شفاف: پوست/تصویر قطعه پس از حذف پس‌زمینه
- SVG: مرز مش و نشانگرهای Pivot و Anchor
- JSON: مختصات دقیق همان PNG خروجی، مقصد اتصال Anchorها، اندازهٔ منبع و محدودهٔ Crop

اگر گزینهٔ Crop فعال باشد، مختصات SVG و JSON به‌طور خودکار به دستگاه مختصات PNG کراپ‌شده منتقل می‌شوند. در JSON مقدار `coordinates` برابر `cropped_image_pixels` است تا دستگاه مختصات مبهم نباشد.

## روش کار

1. تصویر را انتخاب یا روی محیط کار رها کنید.
2. برای PNG شفاف حالت Alpha و برای تصویر دارای پس‌زمینه حالت رنگ گوشه‌ها را انتخاب کنید.
3. آستانه و تلورانس را تا رسیدن ماسک سبز به لبهٔ صحیح تنظیم کنید.
4. Polygon را در صورت نیاز با Vertexها اصلاح کنید.
5. Pivot قطعه و Anchorهای اتصال را روی پیکسل دقیق بگذارید.
6. برای هر Anchor نام قطعه و Anchor مقصد را ثبت کنید.
7. PNG، SVG و JSON را با نام یکسان دریافت کنید.

مرورگر فقط بزرگ‌ترین ناحیهٔ متصل ماسک را نگه می‌دارد؛ بنابراین تصاویر چند آبجکتی باید پیش از ورود به ابزار به یک قطعه در هر فایل محدود شوند.
