# ابزارهای آماده‌سازی خرگوش

فایل `AnchorEditor/index.html` را مستقیماً در مرورگر باز کنید. برنامه دو ابزار مستقل دارد و با نوار بالای صفحه می‌توان بدون حذف هیچ قابلیتی میان آن‌ها جابه‌جا شد. تصاویر فقط در مرورگر پردازش می‌شوند.

## ۱. ماسک، Pivot و Anchor

این همان ویرایشگر اصلی در `rig.html` است و قابلیت‌های زیر را نگه می‌دارد:

- حذف پس‌زمینه با Alpha یا رنگ گوشه‌های تصویر
- ساخت و اصلاح Polygon/SVG
- تعیین Pivot و Anchor و مقصد اتصال قطعات
- خروجی هماهنگ PNG، SVG و JSON
- حالت Sprite Sheet شانزده‌فریمی، تنظیم Crop، چرخش و آینه و خروجی Sheet اصلاح‌شده

## ۲. برش فریم‌های تصویر

ابزار مستقل `crop.html` برای بریدن فریم‌های یک Sprite Sheet به PNGهای جداگانه است:

1. تصویر را انتخاب کنید یا روی نمایشگر رها کنید.
2. تعداد ستون و ردیف را تعیین کنید و «ساخت شبکه» را بزنید؛ برای ۱۶ فریم مقدار پیش‌فرض ۴×۴ است.
3. در حالت «ویرایش فریم‌ها»، کادر را برای جابه‌جایی و گوشهٔ زرد را برای Resize بکشید.
4. برای تنظیم دقیق از جهت‌ها، کلیدهای جهت یا `Shift + جهت` استفاده کنید.
5. هر فریم را جدا ذخیره کنید یا «ذخیره همه» را بزنید تا `frame_01.png` به بعد ساخته شوند.

### حرکت و بزرگ‌نمایی نمایشگر برش

حالت «حرکت و زوم تصویر» فقط دوربین نمایشگر را تغییر می‌دهد و به مختصات Crop دست نمی‌زند:

- Drag برای حرکت آزاد تصویر
- Wheel یا دکمه‌های `−` و `+` برای Zoom
- «فیت تصویر» برای جا دادن کامل تصویر در فضای دسکتاپ
- بازگشت به «ویرایش فریم‌ها» برای جابه‌جایی و Resize کادرها

هر ابزار را می‌توان با دکمهٔ «بازکردن جداگانه» بدون نوار انتخاب ابزار در تب جدید اجرا کرد.
