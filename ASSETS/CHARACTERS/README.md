# Tactical character atlas

Generated using the built-in ImageGen tool for this project. Transparent PNG, four columns and two rows. Row 1: commander, deputy, SF, DF. Row 2: Greed-inspired, Rage-inspired, Pride-inspired brute, Envy-inspired cosmetic zombie skins. These are visual skins; no unimplemented archetype mechanics are claimed.

The existing fallback painter remains usable while the atlas loads. Image regions are animated with small alternating lower-body offsets; a full authored directional animation set remains future art work.
