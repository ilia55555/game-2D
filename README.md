# BLACK VEIL (عنوان کاری) — بازی تاکتیکال با نمای ۲.۵ بعدی از بالا

HTML5 + JavaScript خالص، بدون وابستگی خارجی.

## اجرا

- **GitHub Pages:** Settings → Pages → Deploy from a branch → شاخهٔ `claude/tactical-zombie-game-71kbhd`، پوشهٔ `/ (root)`. آدرس: `https://ilia55555.github.io/game-2D/`
- **محلی:** `index.html` را باز کن، یا نسخهٔ تک‌فایلی `black-veil-offline.html` (ساخت با `node build.js`).

## ساختار

| فایل | کار |
|---|---|
| `js/core.js` | داده‌ها: سلاح‌ها، تیم‌ها، چرخ فرمان (`G.WHEEL`)، فهرست عملیات‌ها (`G.MISSIONS`)، صدا |
| `js/map.js` | تولید نقشه (`crash` و `zones`)، مسیریابی |
| `js/combat.js` | سربازها، سلاح‌ها، فرمان‌ها، هوش جوخه‌ها |
| `js/zombies.js` | رفتار و چینش دشمن‌ها |
| `js/render.js` | رندر، چرخ فرمان، پس‌زمینهٔ منو، نقشهٔ کوچک |
| `js/game.js` | حلقهٔ بازی و بخش مشترک عملیات‌ها |
| `js/missions.js` | منطق اختصاصی هر عملیات (`G.ML.crash`، `G.ML.zones`) |
| `js/ui.js` | منوها، HUD، ورودی |

## عملیات‌ها

- **عملیات ۰۱ «سقوط»** (`crash`): مرحلهٔ اول کارزار.
- **میدان آزمایشی** (`zones`): مرحلهٔ قبلی (مناطق پنج‌گانه و خروج با بالگرد) کنار گذاشته شده و فقط با افزودن `?dev` به آدرس در فهرست عملیات‌ها دیده می‌شود.

## چرخ فرمان

کلیک راست (یا Tab) را نگه دار، ماوس را به سمت فرمان بکش و رها کن. دایرهٔ اصلی فرمان‌های هر دو تیم است؛ گزینهٔ راست «نیروهای ویژه» و گزینهٔ چپ «دلتا فورس» دایرهٔ مخصوص همان تیم را باز می‌کند (برای برگشت روی «بازگشت» برو). «شلیک به نقطه» و «انفجار نقطه» موانع (جعبه، سنگر، خودرو، دیوار) را به اندازهٔ لازم می‌شکنند.

## ایردراپ

هر چند وقت یک بار (و زودتر وقتی مهمات فرمانده کم است) جعبهٔ تدارکات با چتر پایین می‌آید: مهمات و تجهیزات را پر می‌کند و می‌توان سلاح فرمانده و همهٔ نیروها را عوض کرد.
