# پروژه‌ی بازی دوبعدی

این مخزن مربوط به بازی اکشن-پلتفرمر دوبعدی سریعی است که با **Godot 4** و **GDScript** ساخته می‌شود.

## نسخه‌ی فعلی

مرحله‌ی اول از حالت نمونه‌ی خیلی ساده خارج شده و اکنون یک مرحله‌ی کامل آزمایشی با نام **خرابه‌های جنگل** دارد.

ویژگی‌های فعلی:

- مسیر طولانی چندبخشی با هدف حدود ۵ تا ۸ دقیقه برای اولین تجربه
- پنج ناحیه‌ی متفاوت در یک مرحله
- دقیقاً **۲۰ دشمن کوچک** قبل از باس
- دو مدل دشمن: ربات زمینی و درون پرنده
- دروازه‌های انرژی؛ برای ادامه باید دشمن‌های هر بخش را شکست بدهی
- پنج چک‌پوینت
- مسیرهای سرعتی و Speed Pad
- فنر برای پرش‌های بلند
- قسمت سکوبازی عمودی
- تله و تیغه‌های محیطی
- آیتم‌های انرژی قابل جمع‌آوری
- محیط جنگلی علمی‌تخیلی با آبشار، خرابه و فناوری نورانی
- تغییر تدریجی رنگ محیط از فیروزه‌ای به قرمز در نزدیکی قلمرو دشمن
- قهرمان برداری اختصاصی بر اساس کانسپت طراحی‌شده
- دو Sprite اختصاصی برای دشمن‌ها
- باس نهایی **VARKON** با Sprite اختصاصی، ۷۲ واحد سلامتی و چند نوع حمله
- HUD جدید شامل سلامتی، تعداد آیتم‌ها، تعداد دشمن‌های شکست‌خورده و پیشرفت مرحله
- کنترل لمسی برای دستگاه‌های دارای صفحه‌ی لمسی

## ساختار مرحله‌ی اول

مرحله به پنج قسمت تقسیم شده است:

1. آشنایی با حرکت و مبارزه
2. مسیر سرعت
3. خرابه‌های عمودی
4. گانتلت جنگی
5. منطقه‌ی فاسد و ورود به آرنای VARKON

هر قسمت چهار دشمن کوچک دارد؛ در مجموع تعداد دشمن‌های عادی مرحله **۲۰ عدد** است.

بعد از شکست چهار دشمن هر بخش، دروازه‌ی انرژی آن بخش باز می‌شود.

در انتهای مرحله وارد آرنای VARKON می‌شوی.

## کنترل روی کامپیوتر

| کار | کلید |
|---|---|
| حرکت | A / D یا جهت چپ و راست |
| دویدن سریع | Shift |
| پرش | W یا جهت بالا |
| تیراندازی | Space (کلیدهای J/K هم فعلاً جایگزین هستند) |
| نشستن و شلیک زمینی | S یا جهت پایین |
| دویدن سریع | Shift |
| Pause | Esc یا P |

## چطور اجرا و بیلد کنم؟

راهنمای کامل برای کسی که قبلاً با Godot کار نکرده در این فایل قرار دارد:

**[راهنمای اجرای بازی و گرفتن بیلد](docs/راهنمای-اجرا-و-بیلد.md)**

خلاصه:

1. Godot 4 را اجرا کن.
2. شاخه‌ی `games` را دانلود یا Pull کن.
3. فایل `project.godot` را Import کن.
4. دکمه‌ی Run Project یا F6/F5 را بزن.

## فایل‌های مهم

- `scripts/main.gd` ساخت کامل مرحله، دروازه‌ها، HUD و آرنا
- `scripts/player.gd` حرکت و کنترل قهرمان
- `scripts/enemy.gd` هوش دشمن‌های کوچک
- `scripts/boss.gd` باس VARKON
- `scripts/environment.gd` پس‌زمینه و فضای جنگل/خرابه
- `scripts/checkpoint.gd` چک‌پوینت
- `scripts/hazard.gd` تله‌ها
- `assets/enemies/` گرافیک دشمن‌ها
- `assets/bosses/varkon.svg` گرافیک VARKON

## نکته‌ی مهم درباره‌ی گرافیک

شخصیت اصلی دیگر تصویر ثابت نیست. قهرمان به‌صورت یک مدل سه‌بعدی زنده و مفصلی داخل Godot ساخته می‌شود و اعضای بدن مستقل حرکت می‌کنند. دشمن‌ها فعلاً هنوز از Texture موقت استفاده می‌کنند و در مراحل بعدی آن‌ها هم به مدل‌های مفصلی تبدیل می‌شوند.

با این حال این نسخه هنوز **نسخه‌ی هنری نهایی** نیست. مرحله‌ی بعدی کار گرافیکی شامل انیمیشن چندفریمی شخصیت، Tile Set حرفه‌ای، افکت ذرات، سایه و نور پیشرفته و جزئیات بیشتر محیط خواهد بود.

## شاخه‌ی توسعه

توسعه‌ی نسخه‌ی بازی روی شاخه‌ی `games` انجام می‌شود.


## منوی Pause و تنظیمات

در نسخه‌ی فعلی دکمه‌های **PAUSE** و **SETTINGS** در گوشه‌ی بالای بازی وجود دارند.

با زدن **Esc** یا **P** نیز بازی Pause می‌شود. داخل منوی Pause بخش **CONTROLS** تمام کلیدهای اصلی را نشان می‌دهد و بخش **SETTINGS** شامل تنظیم صدا و Fullscreen است.

دروازه‌های فیروزه‌ای/قرمز داخل مرحله باگ نیستند. هر دروازه مربوط به یک بخش است و روی خود آن تعداد دشمن‌های باقی‌مانده نوشته می‌شود. با شکست چهار دشمن همان بخش، دروازه باز می‌شود.


## مدل سه‌بعدی قهرمان

قهرمان اصلی از فایل تصویری استفاده نمی‌کند. مدل زنده در فایل `scripts/hero_model_3d.gd` ساخته می‌شود و با یک SubViewport سه‌بعدی از نمای بغل در بازی دوبعدی نمایش داده می‌شود.

اعضای مستقل فعلی شامل سر، دو گوش، تنه، لگن، بازوها، ساعدها، دست‌ها، ران‌ها، ساق‌ها، کفش‌ها، سه بخش دم و اسلحه است. انیمیشن دویدن، پرش، افتادن، نشستن، شلیک و حرکت دم/گوش‌ها با حرکت واقعی مفصل‌ها انجام می‌شود.

راهنمای توسعه‌ی مدل در فایل `docs/مدل-سه-بعدی-قهرمان.md` قرار دارد.
