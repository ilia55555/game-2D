# VELOCITY — Echoes of the Core / Unity 2.5D

مسیر جدید توسعهٔ بازی **Unity با محیط و مدل سه‌بعدی و دوربین ثابت از بغل** است. پروژه در پوشهٔ [`Unity/`](Unity) قرار دارد. حرکت و مبارزه روی صفحهٔ X/Y و در عمق ثابت Z=0 انجام می‌شوند؛ محیط در هر سه محور عمق دارد.

**وضعیت تحویل:** کد مهاجرت پنج مرحله و سیستم‌های اصلی اضافه شده است. مدل‌های سه‌بعدی کاربر در شاخهٔ مبنا موجود نبودند؛ شخصیت‌ها و محیط فعلاً حجم‌های موقت سه‌بعدی دارند. این نسخه هنوز داخل Unity کامپایل و اجرا نشده است؛ تست نحوی و ساختاری جای تست واقعی موتور را نمی‌گیرد. کیفیت هنری نهایی و تطبیق انیمیشن‌ها به ورود مدل‌ها نیاز دارد.

## باز کردن در Unity

1. شاخهٔ `games` را دانلود و ZIP را خارج کن.
2. در Unity Hub نسخهٔ **6000.6.2f1** را نصب کن. برای خروجی ویندوز، ماژول Windows Build Support را هم نصب کن.
3. **Add → Add project from disk** را بزن و پوشهٔ **`Unity` داخل ریپو** را انتخاب کن؛ پروژهٔ خالی نساز.
4. اجازه بده پکیج Input System و Test Framework دریافت و فایل‌ها Import شوند.
5. صحنهٔ `Assets/Velocity/Scenes/Main.unity` را باز کن؛ یا از منوی **Velocity → Open Game** استفاده کن.
6. Play و سپس **Continue journey** را بزن. اگر Console خطای قرمز دارد، ابتدا همان خطا باید رفع شود.

راهنمای مدل‌ها، مقیاس، جهت و انیمیشن: **[راهنمای Unity](docs/UNITY-MIGRATION.md)**.

## سیستم‌های منتقل‌شده

- مسیر و دادهٔ همان پنج مرحله، ۱۱۸ دشمن، ۳۵۹ جم، ۱۵ چک‌پوینت و ۱۵ شارد.
- کنترل سه‌بعدی شخصیت با حرکت جانبی، پرش دوم، پرش متغیر، زمان ارفاق لبه، دش، نشستن و جلوگیری از بلند شدن زیر سقف.
- Pulse، Scatter و Nova، انرژی، برخورد پیوستهٔ تیر و انفجار با جلوگیری از آسیب دوباره به هدف اصلی.
- پنج نوع دشمن و پنج باس با چرخه‌های حمله، هشدار، فاز دوم و حالت دفاعی.
- سکوهای یک‌طرفه، متحرک و شکننده، تله، لیزر زمان‌بندی‌شده، فنر، آیتم و دروازه.
- ریست مبارزهٔ باس و پاک‌سازی تیرها پس از مرگ؛ ادامه از چک‌پوینت همان نوبت بازی.
- منو، انتخاب مرحله، توقف، نتایج، تنظیمات، رکوردها و ذخیره با نسخهٔ پشتیبان.
- کیبورد، ماوس، کنترل گیم‌پلی با دسته و دکمه‌های لمسی. منو فعلاً با ماوس یا لمس کار می‌کند.
- هفت قطعهٔ موسیقی و ۱۲ افکت قبلی بدون بازتولید فایل صوتی.

## کنترل‌ها

| کار | ورودی |
|---|---|
| حرکت | A / D، فلش‌ها، استیک یا D-pad |
| پرش و پرش دوم | Space / W / بالا، A دسته |
| شلیک | J / Z / کلیک چپ، X دسته |
| دش | Shift / K / X، B دسته |
| سلاح | Q / E / 1 / 2 / 3، RB دسته |
| نشستن | S / پایین |
| توقف | Esc / P / Start |
| تمام‌صفحه | F11 |

## مدل‌های خودت

فایل‌های FBX و تکسچرها را در `Unity/Assets/Velocity/Models/` قرار بده. از هر مدل یک Prefab بساز و آن را در **Velocity → Select 3D Model Catalog** به جایگاه مربوط وصل کن. اطلاعات دقیق در راهنما آمده است. فایل‌های مدل و انیمیشن واقعی هنوز در این ریپو نیستند.

## اعتبارسنجی و بیلد

[گزارش تست و موارد باقی‌مانده](docs/UNITY-VALIDATION.md)

```bash
python tools/verify_unity_source.py
```

تست واقعی: **Window → General → Test Runner → EditMode / PlayMode → Run All**.

خروجی: **Velocity → Build Windows** یا **Velocity → Build Linux**. این مسیرها به نصب Unity، ماژول پلتفرم و فعال بودن مجوز خودت نیاز دارند.

## نسخهٔ قبلی

فایل‌های Godot برای مرجع مهاجرت و حفظ نسخهٔ قبلی نگه داشته شده‌اند؛ Unity هیچ GDScript یا Sprite دوبعدی را در زمان اجرا بارگذاری نمی‌کند. راهنمای قدیمی در [GODOT-LEGACY.md](docs/GODOT-LEGACY.md) است. ذخیره‌های Godot به‌طور خودکار به Unity وارد نمی‌شوند.

## پروژهٔ Godot و ریگ ۱۶ تکهٔ خرگوش

برای جلوگیری از مخلوط‌شدن فایل‌های دو موتور، کل پروژهٔ Godot اکنون در پوشهٔ [`Godot/`](Godot) قرار دارد. برای خرگوش، ۱۶ تصویر شفاف را با نام `frame_01.png` تا `frame_16.png` در [`Godot/assets/rabbit/parts/`](Godot/assets/rabbit/parts) بگذار. راهنمای مهمِ Canvas مشترک و اجرای پیش‌نمایش در [`Godot/assets/rabbit/README.md`](Godot/assets/rabbit/README.md) نوشته شده است.

## ابزار آماده‌سازی قطعات خرگوش

وب‌اپ مستقل [`AnchorEditor`](AnchorEditor) تصاویر Crop‌شده را به PNG شفاف تبدیل می‌کند و مختصات Pivot، Anchor و مرز مش را به‌صورت هماهنگ در JSON و SVG خروجی می‌دهد. برای اجرا، `AnchorEditor/index.html` را در مرورگر باز کن.
