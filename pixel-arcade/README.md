# NOVA: Endless Demolition

یک بازی آرکیدِ دوبعدیِ پیکسل‌آرت: یک اَبَرقهرمان و یک دنیای بی‌انتها (از چپ و راست) از شهر، جنگل، کوه و دریا که **همه‌چیزش تخریب‌پذیر است**.

## اجرا

فایل `index.html` را در مرورگر باز کن (بدون نیاز به سرور یا نصب چیزی). روی موبایل هم با کنترل لمسی کار می‌کند.

برای توسعه: `dev.html` مستقیم از `src/` می‌خواند (نیاز به یک سرور ساده دارد):

```bash
python3 -m http.server 8080
```

و برای ساختنِ دوبارهٔ `dist/game.js` بعد از تغییر کد:

```bash
npm install
```

```bash
npm run build
```

## کنترل‌ها

| کلید | کار |
|---|---|
| `A` `D` / `W` `S` | حرکت؛ در پرواز بالا و پایین |
| `Space` | پرش؛ دوباره در هوا: پرواز؛ دوباره: فرود |
| `S` + `Space` | سوپر جامپ (سقف‌ها را می‌شکافد) |
| `Shift` | سرعتِ فلش: از وسطِ دیوارها رد می‌شود، روی آب می‌دود، در پرواز همه‌چیز را می‌شکافد |
| `C` | کوبشِ زمین از هوا |
| `F` / کلیک راست | مشتِ ویرانگر |
| ماوس / کلیک چپ | نشانه‌گیری و شلیک |
| `1`…`0`، `Q` `E`، چرخِ ماوس | انتخاب سلاح |
| `R` | بمبِ اتمی (وقتی نوارش پُر است؛ با تخریب پُر می‌شود) |
| `P` | نمایش FPS |

## سلاح‌ها

بلستر، راکت، بمبِ خوشه‌ای، نگاهِ لیزری (ساختمان را از وسط می‌بُرد)، **میولنیر** (کلید `5`: کلیک = جرقه‌ی نازک به یک هدف؛ نگه داشتن = شارژ و صاعقه‌ی عظیم از آسمان که زنجیروار به همه‌ی دشمنانِ نزدیک می‌خورد و پودرشان می‌کند. تنظیماتش در `THOR` داخل `src/thor.js`)، شهاب‌سنگ، سیاه‌چاله، گردباد، تیغه‌های یخ، پرتوِ آسمانی، و بمبِ اتمی.

## چطور کار می‌کند

- **دنیا** (`src/world.js`): شبکه‌ای از سلول‌های ۴ پیکسلی که تکه‌تکه و بی‌انتها ساخته می‌شود. هر ماده جانِ خودش را دارد (شیشه، آجر، بتن، فولاد…). هر سازه‌ای که اتصالش به زمین قطع شود یک‌تکه سقوط می‌کند و موقع برخورد خرد می‌شود. چوب و برگ آتش می‌گیرند و آتش پخش می‌شود. مخزن‌های سوخت زنجیره‌ای منفجر می‌شوند.
- **قهرمان** (`src/hero.js`): بدنش اسکلتِ سه‌بعدیِ pixelfx است که با لباسِ خودش رنگ شده؛ هر ژست (دویدن، پرواز، مشت، نشانه‌گیری) زنده حل و رسم می‌شود.
- **افکت‌ها**: انفجارها، صاعقه، شهاب‌سنگ، سیاه‌چاله، گردباد، قارچِ اتمی و… از کتابخانهٔ [pixelfx](vendor/pixelfx) هستند؛ خرده‌ریز و دود و جرقهٔ انبوه را ذراتِ خودِ بازی (`src/particles.js`) می‌سازند.
- **دشمن‌ها** (`src/enemies.js`): هرچه بیشتر خراب کنی سطحِ تعقیب (ستاره‌ها) بالاتر می‌رود: سرباز، چترباز، تانک، هلیکوپتر.
- موتور گرافیکی ندارد: همه‌چیز نرم‌افزاری در یک بافرِ ۶۴۰×۳۶۰ رسم می‌شود، هم‌قالب با فریم‌های pixelfx.
