# نور و سایه — بازسازی بازی از صفر

این پوشه عمداً **فقط یک شخصیت اصلی و یک دشمن** دارد. تمام حرکات با اسکلت دوبعدی مفصلی متحرک اجرا می‌شوند. هیچ موج دشمن، افکت تصادفی یا سیستم اضافی از نسخه‌های قبلی باقی نمانده است.

## اجرا
از آنجا که جاوااسکریپت اصلی از ES Modules استفاده می‌کند، فایل HTML را به جای بازکردن مستقیم به شکل `file://`، با یک سرور محلی اجرا کنید:

```bash
cd بازی
python -m http.server 8080
```

سپس `http://localhost:8080/` را باز کنید. نیازی به npm، CDN یا اینترنت نیست.

## کنترل‌ها
A/D حرکت، Alt راه‌رفتن آرام، Space پرش دوبل، Shift دش، J حمله و کمبو، K حمله سنگین، L دفاع، **نگه‌داشتن F شعله‌افکن از کف دست**، **E گردباد آتش**، I نمایش و آزمون همهٔ حالت‌های حرکت دو شخصیت، P توقف و R شروع مجدد.

## چهار ماژول واقعی PixelFX
- `fire/flamethrower` — افکت از **کف دست شخصیت اصلی** شروع می‌شود و با جهت او تغییر جهت می‌دهد؛ ضربهٔ آتش فقط هنگام برخورد به دشمن ثبت می‌شود.
- `fire/fire-tornado` — گردباد آتش در مقابل شخصیت ظاهر می‌شود و به دشمن داخل شعاع آسیب می‌زند.
- `weather/clouds` — ابرهای متحرک فقط در لایهٔ آسمان دیده می‌شوند.
- `pickups/heart-pickup` — قلب قابل‌جمع‌آوری، **۳۵ واحد جان** فقط وقتی قهرمان زخمی است.

ماژول‌ها با همان API اصلی `createFrame`، `createFx`، `update`، `draw` و `composite` استفاده می‌شوند و فایل‌های اصلی کتابخانه همراه وابستگی‌هایشان در `vendor/pixelfx` وجود دارند.
